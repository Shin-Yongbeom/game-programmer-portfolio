# 캠퍼스 마법지도 (More Adore Campus Map)

대학 캠퍼스에서 필요한 정보를 지도 위에서 한 번에 다루는 모바일 서비스입니다. 앱과 웹, 서버,
인프라를 혼자 만들어 배포했고 6개월 넘게 직접 운영했습니다. 별도의 유료 마케팅 없이 캠퍼스
안에서 입소문만으로 누적 이용자 1,000명을 넘겼습니다.

운영 중인 서비스라 서버와 인프라 소스는 공개하지 않고, 여기서는 무엇을 만들었고 어떤 역할을
했는지만 정리합니다.

## 무엇을 만들었나

지도가 중심입니다. MapLibre로 캠퍼스 벡터타일 지도를 그리고, 여러 캠퍼스를 선택해 오갈 수
있게 했습니다. 캠퍼스 건물 안이나 지하처럼 네트워크가 잘 안 되는 곳을 대비해 지도 타일과
경로 그래프를 오프라인 자산으로 미리 내려받아 쓰도록 만들었습니다.

지도 위에 생활에 필요한 것들을 얹었습니다. 공지사항, 날씨, 대중교통 실시간 도착 정보를
붙였고, 시간표는 사진을 찍으면 OCR로 읽어 입력하도록 했습니다. 친구를 맺고 위치를 공유하거나
콕 찌르는 소셜 기능, 장소 제보와 피드백, 푸시 알림도 넣었습니다. UI는 한국어, 영어, 일본어,
중국어를 지원합니다. 이후에는 같은 백엔드를 쓰는 웹 버전으로 범위를 넓혀 따로 배포했습니다.

## 어떤 역할을 했나

기획 방향부터 클라이언트, 백엔드, 인프라, 배포, 운영, 사용자 대응까지 전부 혼자 했습니다.

클라이언트는 React Native로 만들었습니다. MapLibre 렌더링 파이프라인과 오프라인 자산 로딩을
구성하고, 인증·캠퍼스·테마·소켓·교통 설정 같은 앱 전역 상태를 컨텍스트로 나눴습니다.
서버 통신은 axios로 감싸고 OCR은 별도 클라이언트로 분리했으며, 화면마다 다른 캐시 정책이
필요해서 React Query의 키 네임스페이스와 무효화 규칙을 직접 설계했습니다. OTP와 소셜 로그인
흐름, 딥링크 복원, 소켓 재연결도 여기서 처리했습니다.

백엔드는 Express와 TypeScript로 작성했습니다. 요청 생애주기를 미들웨어, 서비스, 데이터 접근
계층으로 나누고 응답과 에러 포맷을 표준화했습니다. JWT 발급과 로테이션, 레이트리밋, CORS,
업로드 보안을 다뤘고, 데이터는 PostgreSQL과 Redis에 PgBouncer를 앞에 두고 썼습니다. OCR
서비스와 지도 글리프(폰트) 서버는 따로 운영했고, 집계와 정리를 위한 크론 배치, 헬스체크와
메트릭, 구조화 로깅을 붙였습니다.

인프라는 클라우드에 Public과 Private 서브넷을 나누고 운영 접근을 Bastion 세션 하나로만
열어 뒀습니다. 배포 절차와 보안 경계, 캐시 무효화 규칙을 문서로 남겨 코드와 함께 관리했고,
백업에서 서비스를 복원하는 리허설도 미리 해 뒀습니다. 위치기반서비스사업 신고 같은 행정
처리도 직접 했습니다. 클라우드 예산이 초과됐을 때는 로드밸런서를 정리하고 경로를 줄이는
식으로 비용과 가용성을 직접 저울질했습니다.

## 사용한 기술

클라이언트는 React Native 0.77, React Navigation, TanStack React Query, MapLibre, Firebase
Cloud Messaging, Axios, NativeWind, TypeScript를 썼습니다. 백엔드는 Node.js, Express,
TypeScript, PostgreSQL, Redis, PgBouncer, Socket.IO, 오브젝트 스토리지, OCR 서비스로
구성했습니다. 인프라는 클라우드 VPC와 Bastion, 웹 버전을 위한 정적 호스팅, systemd 서비스와
크론 배치를 사용했고, 지도 쪽으로는 벡터타일 생성·배포와 글리프 PBF 버전 관리를 다뤘습니다.

## 개발 과정과 현재 상황

2026년 1월에 프론트엔드 v1.0.0을 시작하면서 벡터타일과 정적 자산 파이프라인을 정리했습니다.
2월에 첫 모바일 릴리스를 냈고 지도와 친구 위치 부트스트랩을 안정화했습니다. 3월에서 4월
사이에 프로덕션 배포를 하고 서버 배포 절차를 정립했으며, 바텀시트와 웹뷰 흐름을 다듬었습니다.
5월에서 6월에는 친구·콕찌르기·딥링크 복원과 교통 경로 API, 토폴로지 스냅샷 배포를 작업했고,
7월에는 릴리스 빌드를 정비하면서 복구 리허설과 행정 관련 문서를 만들었습니다. 8월 이후로는
웹 버전을 확장하고, 크론과 CORS 설정을 현행화하고, 실시간 도착 정보 문구와 모바일 시트
조작감을 사용자 피드백에 맞춰 고쳤습니다.

누적 커밋은 약 350건이고 그중 300건 이상이 배포 후 6개월 동안의 운영과 개선입니다. 지금도
운영과 유지보수를 이어가고 있으며, 실사용자 피드백을 반영해 UX와 데이터 정합성을 계속
다듬고 있습니다.
